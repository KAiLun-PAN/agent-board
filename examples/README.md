# Examples

| 目录 | 场景 | 看点 |
|---|---|---|
| [video-production/](video-production/) | AI 视频生产线（数字人、配音、动画、混音、剪辑工程） | 项目专属规则（付费 API 约束）、`⛔阻塞` 等锁的写法、用 `VERSION_HISTORY.md` 作为历史文件名 |

安装时用自定义文件名即可沿用示例风格：

```bash
curl -fsSL https://raw.githubusercontent.com/KAiLun-PAN/agent-board/main/install.sh | bash -s -- --history VERSION_HISTORY.md
```
