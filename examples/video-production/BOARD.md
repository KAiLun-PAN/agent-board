# 示例：视频生产线看板（脱敏节选）

> 来自作者真实项目《AI视频进化史》，多个 Agent 接力完成数字人、配音、动画、混音、剪辑工程。
> 注意项目在通用协议之外追加了自己的专属规则（第 7、8 条）。

## 使用协议（强制）

1. **先登记，后动手**：开始任务前，在「进行中任务」表加一行，并在「文件锁」表登记将要修改的文件/目录。
2. **文件锁独占**：同一文件/目录同一时间只允许一个 Agent 修改。发现目标文件已被锁定 → 找持有者协调或等锁释放。
3. **读不占锁**：只读不改无需登记；但动手前重新读本看板。
4. **粒度最小化**：只锁本次真正要改的文件/目录；能新建文件就不改共享文件。
5. **完成即释放**：释放文件锁、行移入「最近完成」、在 VERSION_HISTORY.md 追加一条版本记录。
6. **阻塞即标注**：无法继续时把状态改为 `⛔阻塞`，不要占着锁沉默。
7. **提交规范**：`[任务ID] 简述`；大文件产物（mp4/wav/模型权重）不入库。
8. **付费 API 约束**：调用付费云端生成 API 前，在任务行注明，并先确认本地缓存不可复用。
