# 协同任务看板 BOARD

> 多 Agent 协作的**唯一调度入口**。任何 Agent 动手改文件前，必须先读本看板并按协议登记。
> 历次完成记录见 [HISTORY.md](HISTORY.md)。协议全文见 `AGENTS.md` / `CLAUDE.md` 中的 Agent Board 段落。

## 使用协议（速查）

1. **先登记，后动手**：领任务写入「进行中」，要改的文件写入「文件锁」。
2. **文件锁独占**：同一文件同一时间只允许一个 Agent 修改；读不占锁。
3. **锁最小、新建优先**：不要整仓加锁。
4. **完成即释放**：释放锁 → 移入「最近完成」→ `HISTORY.md` 顶部追加一条。
5. **阻塞即标注**：状态改 `⛔阻塞` 并写明等待项。

- 任务 ID：`T-序号`（不复用） · Agent：`A-<工具>-<短名>` · 状态：`📋待办` `🔵进行中` `⛔阻塞` `✅完成` `❌取消`
