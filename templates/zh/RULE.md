## 多 Agent 协同协议（Agent Board）

本项目可能同时有多个 Agent（Codex / Claude Code / Gemini / Cursor / 人类）在工作。
协同只靠两个文件：**任务看板 `BOARD.md`** 和 **历史记录 `HISTORY.md`**（都在项目根目录）。

**每次任务都必须遵守：**

1. **先看板，后动手**：开始任何会改文件的任务前，先读 `BOARD.md`，再按需读 `HISTORY.md` 最近几条。
2. **领任务 + 占文件**：在「🔵 进行中」加一行（任务 ID、内容、你的 Agent 标识、时间），并在「🔒 文件锁」登记你将要修改的文件/目录。
3. **文件锁独占**：目标文件已被别人锁定 → 不要改，换任务、等释放或在备注里协调。只读不需要加锁。
4. **锁最小、新建优先**：只锁真正要改的文件；能新建文件就不改共享文件。
5. **完成即释放**：任务完成 → 删除你的文件锁 → 任务行移到「✅ 最近完成」→ 在 `HISTORY.md` **最上面**追加一条记录。
6. **历史只写摘要 + 指针**：改了什么、为什么、产物/证据在哪、详细过程在哪；不要粘贴大段日志。
7. **阻塞要标注**：做不下去就把状态改为 `⛔阻塞` 并写明等待什么，**不要占着锁沉默**。
8. **需要上下文时**：先查 `HISTORY.md` 里相关条目，顺着指针去读，不要每次重新全量探索仓库。

- 任务 ID：`T-序号`，按领取顺序递增、不复用；Agent 标识：`A-<工具>-<短名>`，如 `A-codex-api`、`A-claude-ui`。
- 状态：`📋待办` / `🔵进行中` / `⛔阻塞` / `✅完成` / `❌取消`。
- 提交信息（如使用 git）：`[T-012] 一句话简述`。
